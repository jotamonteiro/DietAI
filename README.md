# 🏋️‍♂️ Sistema de Criação de Dietas e Treinos

**Aplicação em Java (Console)**

Este projeto foi desenvolvido com o objetivo de auxiliar iniciantes na academia, fornecendo um sistema simples e direto para criação de **dietas**, **treinos básicos** e cálculo de **IMC**.
Por meio de interações no console, o usuário informa seus dados e recebe recomendações automáticas baseadas em regras de negócio definidas.

---

## 📌 Funcionalidades

* 📏 **Cálculo de IMC** e classificação do usuário.
* 🔥 **Estimativa de gasto calórico diário (TDEE)**.
* 🎯 **Sugestão de dieta automática** com base no objetivo:

  * Ganho de Massa
  * Perda de Peso
  * Manutenção
* 🏋️ **Geração de treinos personalizados**:

  * Iniciante
  * Intermediário
  * Avançado
* 📋 **Exibição dos resultados** diretamente no console.
* ❌ **Sem banco de dados**: todas as informações são processadas em tempo real.

---

## 🧠 Regras de Negócio (Resumo)

* O IMC é calculado usando a fórmula:
  **IMC = peso / (altura²)**
* O sistema classifica o usuário conforme a tabela padrão da OMS.
* O gasto energético diário é gerado com base em um multiplicador simples.
* A dieta sugerida é ajustada pelo objetivo informado.
* Os treinos são definidos conforme o nível de experiência.

---

## 📌 Observações Importantes

* O objetivo deste sistema é **educacional** e voltado para iniciantes em programação e fitness.
* As sugestões de dieta e treino são **básicas** e **não substituem** acompanhamento profissional.
